# Lộ trình lập trình thi đấu C++

Tổng hợp có hệ thống từ cơ bản đến thi đấu: thư viện STL, cấu trúc dữ liệu, thuật toán và các dạng bài thường gặp. Mỗi mục có độ phức tạp, ứng dụng điển hình và đoạn code minh họa.

#### 1 · Cơ bản

Biến, vòng lặp, mảng, vector, string, sắp xếp, vét cạn, tham lam đơn giản, DP một chiều.

#### 2 · Trung cấp

map/set, priority_queue, nhị phân, hai con trỏ, BFS/DFS, DSU, Dijkstra, DP kinh điển.

#### 3 · Nâng cao

Segment tree, BIT, LCA, luồng cơ bản, DP trên cây và bitmask, KMP, hash, hình học.

#### 4 · Thi đấu

Dinic, FFT/NTT, Mo, pb_ds, Aho-Corasick, suffix array, cấu trúc bền vững (persistent).
